# The Nonstop Ibiza Experience (Canvas2D port)

A JavaScript, Canvas 2D and Web Audio port of **The Nonstop Ibiza Experience**
by Orange, released at Assembly 2000. It was reconstructed by disassembling the
released `demo.exe`.

The port keeps the original 512×384 presentation, uses the released image
assets, and replays the original FastTracker II XM soundtrack directly in
JavaScript.

This port was made with Codex 5.6 Sol Ultra.
